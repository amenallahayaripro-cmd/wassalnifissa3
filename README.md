# Wassalni

Application Flutter de livraison (Expéditeur ↔ Livreur) - montants en dinar tunisien (DT).

- Bordereaux avec code-barres, QR de clôture, suivi des statuts
- Dashboard expéditeur avec plage de dates et montant encaissé
- Livreur : détail du colis, appel et SMS en un clic, alertes d'enlèvement dans son périmètre

Les données sont simulées (`MockDB`), il n'y a pas encore de serveur.

## Obtenir l'APK
Onglet **Actions** → dernier run « Build APK » → artefact `wassalni-apk`.
